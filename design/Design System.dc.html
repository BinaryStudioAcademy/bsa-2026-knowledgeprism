Responsive rules

Intentional layout changes per breakpoint — never a scaled-down desktop screen.

Desktop · 1440

Sidebar + content. 4-col feature grids. Tables show all columns.

Tablet · 1024

Collapsed icon sidebar. 2-col grids. Tables drop secondary columns.

Mobile · 390

Header + hamburger nav. 1-col grids. Tables become stacked cards.

Brand

The faceted prism mark — three tonal facets of the accent green, forming a gem that refracts scattered input into structure.

KnowledgePrism

Minimum clear space: half the mark's width on all sides. Never recolor the facets individually or add a drop shadow.
