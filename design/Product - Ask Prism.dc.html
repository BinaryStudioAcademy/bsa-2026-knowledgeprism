What's the sensor resolution on the camera system, and how does it connect to the ISP?

The camera system uses a 48 Megapixel sensor array with a variable f/1.8–f/2.4 aperture, optimized for low-light performance Camera system.

It connects to the ISP via a dedicated 4-lane MIPI CSI-2 bus, bypassing standard data lanes to minimize latency during continuous capture Processor architecture.
